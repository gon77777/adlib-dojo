# アドリブ道場(仮称)

ギター・ベース・鍵盤のアドリブ練習アプリ。仕様書 v0.1 の M0〜M4 + M5の一部(M2は指板タップ発音のみ)まで実装済み。

## 現在できること
- 指板SVG(ギター/ベース4・5弦、左利き反転、音名/度数/なし表示、表示範囲の切替: ギター0〜15 / 8〜22)
- ポジション自動生成(ペンタ・ブルース・ナチュラルマイナー・ドリアン・ミクソリディアン・メジャー)
- 指板タップでKarplus-Strong合成音が鳴る
- `npm test` でCマイナーペンタのポジション1・2が添付図と一致することを確認

## ビルド
GitHubにpushするとActionsが横向き固定のデバッグAPKを作る(chord-trainerと同じ手順)。
手元で確認するだけなら `www/index.html` をブラウザで開く。

- バッキング: コードループ(5進行)、BPM 40〜200+タップテンポ、スウィング(8分/16分)、ドラム5種・ベース5種・コード4種を合成、カウントイン、音量、再生中のコードトーン強調

- お題: 14種(Lv1〜5、音を絞る・リズム型・休符・モチーフ・コール&レスポンス・奏法・コードトーン等)。「できた」「もう少し」を記録
- 記録: 練習時間(7日グラフ・連続日数)、達成マトリクス、苦手スケール、JSONバックアップ/読み込み/リセット

## 次のマイルストーン
残り: 実機での試聴・調整(遅延、音量バランス、ピアノ音源の追加は任意)
- 教本タブ: 共通ルール20(R14〜R17=ルート地図・4度・オクターブ・E-F/B-C、R18=近接音、R19=1弦だけ、R20=ルートからの関係)・考え方12・入門2・用語辞典30。お題カードのルールID(R1など)から該当ページへ移動
- 理論タブ: 初見スケール攻略カード(音をタップして自作→自動分析→指板に反映)、コードトーン早見、モード対応表
- 鍵盤モード(3オクターブ、オクターブ範囲=ポジション)、設定(遅延補正・ギターのチューニング)、再生中の画面スリープ防止、バックグラウンドで自動停止

- 指板タブ: ルート地図(6・5・4弦のルート、4度/オクターブ表示)、指板クイズ(「この音は?」「どこ?」をタップで自動判定、間違い・遅い所を優先、反応時間を記録、成績はバックアップ対象)
- 覚えなくても弾ける方法: 足場外しモード(全部の音→ルートだけ→コードトーンだけ→表示なし、再生中は周ごとに自動で減る)、キーシャッフル(バッキングタブ。進行を1/2/4周するごとにキーが変わり、停止で元のキーに戻る)、1本だけ表示(練習タブ)、近接音・1弦・足場外し・キーシャッフルのお題を追加
- 基礎タブ: 基礎練習8種(クロマチック/スパイダー/オルタネイト/スケール上下行3音・4音/弦移動/ハンマリング・プルオフ/リズム型)。押さえる音を点滅で案内(青緑=次の3音、数字=指)、ピッキング表示、スピードビルダー(N小節ごとにBPM上昇)。できた回数・最高BPM・練習時間を記録タブに表示、バックアップ対象

## フレーズタブ(実践フレーズを作る)
- ビルダー: 指板をタップして音を置き、リズム格子(8分/16分、1・2・4小節)に並べる。伴奏と同時再生/音だけ再生、休符・戻す、度数の列表示、「自分のリック」保存、度数・音名・TABのテキスト書き出し(コピー)
- 変形: 繰り返す/1つ・2つずらす(スケール上)/リズム(裏にずらす・詰める・広げる・別の型)/最後だけ変える/別ポジションに移す
- お手本: 初級30種(マイナーペンタ12・ブルース10・メジャーペンタ8)。キー・ポジションに自動で移調し指板に表示。「真似する→変える→自分のものにする」の進捗を記録
- ガイドトーン: 進行の各コードの3度・7度(トライアドは5度)を指板に表示、再生中は現在のコードに追従。次のコードへ半音以内でつなぐ組み合わせと、全体をつなぐ線を表示
- ウィザード: リズム→使う音→終わりの音→生成(4小節。1〜3小節は同じ型、4小節目は前半+長い終わりの音)
- 自分のリックと進捗は localStorage 'adl_phrase'、記録タブのバックアップ(JSON)にも含まれる。コードは core/phrase.js(純粋関数・テストあり)、data/licks.js、ui/phrase.js
